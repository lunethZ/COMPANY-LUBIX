# HU-036 — Ver productos destacados

## Identificación

| Campo | Valor |
|---------|---------|
| ID | HU-036 |
| Título | Ver productos destacados |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-036 |

---

## Historia

Como comprador de Lubix, quiero ver los productos destacados en la página principal, para descubrir productos populares y recomendados por la plataforma.

---

## Criterios de aceptación

### CA-036.1 — Sección de productos destacados

**Dado que** ingreso a la página principal de la plataforma,

**cuando** se carga el contenido,

**entonces** debe mostrarse una sección identificada como "Productos destacados" con los productos seleccionados por la plataforma.

### CA-036.2 — Carrusel de navegación

**Dado que** estoy en la sección de productos destacados,

**cuando** visualizo los productos,

**entonces** deben mostrarse en formato de carrusel con botones de navegación para desplazarse entre ellos de izquierda a derecha.

### CA-036.3 — Rotación automática

**Dado que** estoy en la página principal y no interactúo con el carrusel,

**cuando** transcurren unos segundos,

**entonces** el carrusel debe rotar automáticamente mostrando el siguiente producto destacado de forma fluida.

### CA-036.4 — Navegación al detalle

**Dado que** estoy en la sección de productos destacados,

**cuando** hago clic en cualquiera de los productos del carrusel,

**entonces** debe redirigirme a la página de detalle de ese producto.
