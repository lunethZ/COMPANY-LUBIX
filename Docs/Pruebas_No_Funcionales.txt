PNF-003 | Seguridad | Contraseñas con bcrypt (RNF-004)
--------------------------------------------------------------------------------

  DESCRIPCIÓN:
    Verificar que las contraseñas se almacenen hasheadas con bcrypt
    y nunca en texto plano.

  PRECONDICIONES:
    Backend ejecutándose. Usuario registrado en base de datos.

  DATOS DE ENTRADA:
    Contraseña del usuario: "Password123"

  PASOS DE EJECUCIÓN:
    1. Conectar a PostgreSQL.
    2. Ejecutar: SELECT hashed_password FROM users WHERE email='usuario@test.com'.
    3. Verificar que el valor empiece con "$2b$" (prefijo bcrypt).
    4. Verificar que NO sea la contraseña en texto plano.

  RESULTADO ESPERADO:
    El campo hashed_password contiene un hash bcrypt, no texto plano.

PNF-004 | Seguridad | Tokens JWT con expiración (RNF-003)
--------------------------------------------------------------------------------

  DESCRIPCIÓN:
    Verificar que los tokens JWT tengan tiempo de expiración configurado.

  PRECONDICIONES:
    Backend ejecutándose. Usuario autenticado.

  DATOS DE ENTRADA:
    Access token obtenido del login.

  PASOS DE EJECUCIÓN:
    1. Login exitoso para obtener access_token.
    2. Decodificar el token (jwt.io o base64).
    3. Verificar campo "exp" (expiración).
    4. Verificar que la diferencia con "iat" (emisión) sea 60 minutos.
    5. Esperar a que expire y verificar que se rechaza.

  RESULTADO ESPERADO:
    Token tiene expiración de 60 minutos. Token expirado retorna 401.

  RESULTADO OBTENIDO:
    Pendiente de ejecución - Se requiere autenticación exitosa.
