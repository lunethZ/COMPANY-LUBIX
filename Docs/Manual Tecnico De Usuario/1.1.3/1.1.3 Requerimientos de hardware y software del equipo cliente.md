# 1.1.3 Requerimientos de hardware y software del equipo cliente

## Consideraciones generales

LUBIX opera bajo una arquitectura cliente-servidor de tres capas. El procesamiento de la lógica de negocio, la persistencia de datos y el almacenamiento de archivos se ejecutan en la infraestructura central; el equipo cliente únicamente se encarga de presentar la interfaz, mantener una conexión estable con la API y permitir la interacción del usuario. Por consiguiente, los requerimientos descritos en este apartado se refieren exclusivamente a los equipos de escritorio, portátiles y dispositivos móviles desde los cuales se accede a la plataforma, y no sustituyen los requisitos de servidor, contenedores, base de datos o respaldo, los cuales se documentan en la Ficha Técnica del sistema.

El cumplimiento de estos requerimientos debe verificarse antes del primer acceso y revisarse periódicamente, especialmente cuando el fabricante del sistema operativo o del navegador deja de emitir actualizaciones de seguridad. Un equipo que no cumpla las condiciones mínimas puede experimentar lentitud, errores de renderizado, fallos de autenticación o exposición a riesgos de seguridad, situaciones que no serán atribuibles a un defecto de la plataforma.

Los valores aquí establecidos constituyen una línea base. La organización puede imponer requisitos adicionales derivados de sus políticas internas de seguridad, administración de dispositivos, redes corporativas o acuerdos con proveedores.

## Requerimientos de hardware

### Equipo de escritorio o portátil para acceso web

| Componente | Mínimo | Recomendado |
|---|---|---|
| Procesador | 2 núcleos, 1.6 GHz | 4 núcleos, 2.0 GHz o superior |
| Memoria RAM | 2 GB, con al menos 1 GB disponible para el navegador | 4 GB o más, con al menos 2 GB disponibles |
| Espacio libre en disco | 500 MB | 1 GB o más |
| Resolución de pantalla | 1280 × 720 píxeles | 1920 × 1080 píxeles |
| Interfaz de red | Ethernet o Wi-Fi integrado | Ethernet o Wi-Fi de doble banda |
| Periféricos | Teclado y ratón o panel táctil | Teclado, ratón y, opcionalmente, cámara y micrófono |
| Conexión a Internet | 10 Mbps de bajada y 2 Mbps de subida | 20 Mbps de bajada y 5 Mbps de subida |
| Latencia de red | Inferior a 150 ms | Inferior a 80 ms |

> **Nota:** los sistemas operativos Windows 11 y macOS recientes pueden exigir por sí mismos 4 GB o más de RAM. En equipos destinados a tareas administrativas, atención simultánea de varias pestañas o gestión de catálogos extensos, se recomienda 8 GB de RAM. La Ficha Técnica del sistema establece 2 GB como línea base para el cliente web; este manual precisa la recomendación operativa.

### Dispositivo móvil para acceso mediante aplicación

| Componente | Mínimo | Recomendado |
|---|---|---|
| Sistema operativo Android | Android 8.0 (API 26) | Android 11 o superior |
| Sistema operativo iOS | iOS 13 | iOS 16 o superior |
| Memoria RAM | 2 GB | 4 GB o más |
| Espacio libre en disco | 100 MB | 250 MB o más |
| Tamaño de pantalla | 5 pulgadas | 6 pulgadas o superior |
| Cámara | No indispensable | 8 MP o superior, para fotografías de perfil o soporte |
| Conectividad | Wi-Fi o datos móviles 4G | Wi-Fi o datos móviles 5G |
| Batería | Autonomía suficiente para la jornada de uso | Carga rápida o batería de larga duración |

> La aplicación móvil está optimizada para teléfonos inteligentes. Su ejecución en tabletas es posible, pero no se certifica una experiencia plenamente adaptada a ese formato. Los dispositivos con modificaciones no oficiales del sistema operativo (root en Android o jailbreak en iOS) no son compatibles por razones de seguridad.

## Requerimientos de software

### Sistema operativo del equipo de escritorio

| Sistema operativo | Versiones admitidas | Observaciones |
|---|---|---|
| Microsoft Windows | Windows 10 versión 22H2 o superior; Windows 11 | Debe contar con actualizaciones de seguridad al día |
| Apple macOS | macOS 12 Monterey o superior | Se recomienda la versión estable más reciente compatible con el equipo |
| GNU/Linux | Ubuntu 20.04 LTS o superior; Fedora 36 o superior; distribuciones equivalentes | Se admite siempre que el navegador se encuentre actualizado |

No se garantiza el funcionamiento en sistemas operativos sin soporte del fabricante, en versiones de escritorio de prueba o en entornos modificados que alteren los mecanismos de seguridad del navegador.

### Navegador web

LUBIX es una aplicación web moderna que requiere un navegador con soporte para JavaScript, hojas de estilo actuales, almacenamiento local y conexiones cifradas TLS 1.2 o TLS 1.3. Se admiten las dos versiones más recientes de los siguientes navegadores:

| Navegador | Versiones admitidas | Canal recomendado |
|---|---|---|
| Google Chrome | Últimas dos versiones estables | Actualización automática |
| Microsoft Edge | Últimas dos versiones estables | Actualización automática |
| Mozilla Firefox | Últimas dos versiones estables | Actualización automática |
| Apple Safari | Últimas dos versiones estables | Actualizaciones del sistema macOS o iOS |

Internet Explorer y los navegadores basados en motores obsoletos no son compatibles. Las versiones anteriores a las dos últimas de cada navegador pueden funcionar con degradación parcial, pero no reciben soporte ni garantía de compatibilidad.

### Configuración mínima del navegador

El navegador debe mantener la siguiente configuración para el correcto funcionamiento de LUBIX:

- **JavaScript habilitado.** Es indispensable para la carga de la interfaz y la ejecución de las operaciones.
- **Cookies y almacenamiento local habilitados.** LUBIX utiliza estos mecanismos para conservar la sesión, el tema visual y preferencias básicas.
- **Ventanas emergentes permitidas para el dominio de la plataforma.** Algunos flujos de autenticación, descargas de facturas o confirmaciones pueden abrir una ventana adicional.
- **Descargas permitidas.** Necesario para obtener facturas, comprobantes y documentos adjuntos.
- **TLS 1.2 o superior habilitado.** Las conexiones con la plataforma deben realizarse mediante HTTPS en entornos productivos.
- **Zoom al 100 %.** Se admite ampliación hasta el 200 % para accesibilidad, siempre que la interfaz siga siendo operable.
- **Extensiones de bloqueo o modificación de contenido desactivadas para el dominio de LUBIX** cuando se realicen labores de diagnóstico. Bloqueadores agresivos, extensiones de privacidad o scripts de personalización pueden interferir con la autenticación y con las llamadas a la API.
- **Fecha y hora del equipo sincronizadas.** Una desviación significativa puede invalidar tokens de sesión o generar errores de certificado.

### Software complementario

| Software | Requisito | Uso |
|---|---|---|
| Lector de PDF | Cualquier visor actualizado | Consulta y descarga de facturas, comprobantes y documentos |
| Cliente o servicio web de correo | Cuenta activa con acceso a la bandeja de entrada y a la carpeta de correo no deseado | Verificación de cuenta, recuperación de contraseña y notificaciones |
| Antivirus y firewall | Solución actualizada, cuando la política institucional lo exija | Protección del equipo cliente |
| Gestor de contraseñas | Opcional, autorizado por la organización | Resguardo seguro de credenciales |
| Herramienta de compresión | Opcional | Preparación de archivos adjuntos para tickets de soporte |

No es necesario instalar Python, Node.js, Docker, PostgreSQL, clientes de MinIO ni ninguna herramienta de desarrollo en el equipo del usuario final. Estos componentes corresponden a la operación del servidor y al entorno de desarrollo, y su instalación en estaciones de trabajo no forma parte del uso normal del sistema.

### Requerimientos para la aplicación móvil

- Sistema operativo Android 8.0 o superior, o iOS 13 o superior.
- Aplicación instalada desde el canal oficial definido por la organización o desde la tienda de aplicaciones corporativa.
- Actualizaciones de la aplicación y del sistema operativo al día.
- Permisos de cámara y almacenamiento habilitados cuando el usuario necesite cargar fotografías, documentos o evidencias.
- Permisos de notificaciones habilitados si la organización utiliza avisos transaccionales.
- Conexión a Internet estable mediante Wi-Fi o red móvil.
- Espacio libre suficiente para instalación, actualizaciones y archivos temporales.

## Requerimientos de red y seguridad

- Acceso saliente por el puerto **443/TCP** hacia el dominio o los dominios de LUBIX. No se requieren puertos de entrada abiertos en el equipo cliente.
- Resolución DNS correcta para el dominio de la plataforma y, cuando aplique, para el portal de la mesa de ayuda.
- Si la organización utiliza proxy inverso, firewall perimetral o filtrado de contenido, deben autorizarse los dominios de LUBIX y los servicios asociados.
- Certificado digital válido y confiable en el equipo cliente. Los errores de certificado deben reportarse a la mesa de ayuda y no deben omitirse mediante excepciones permanentes del navegador.
- Uso preferente de redes corporativas o conexiones confiables. En redes públicas o compartidas se recomienda el uso de VPN institucional cuando la organización la proporcione.
- Bloqueo automático del equipo y cierre de sesión al finalizar la jornada, especialmente en equipos compartidos.
- Sincronización horaria mediante NTP o el servicio del sistema operativo.

## Criterios de verificación antes de reportar un incidente

Antes de contactar a la mesa de ayuda, el usuario debe realizar las siguientes comprobaciones básicas:

1. Verificar que la conexión a Internet funcione y que otros sitios respondan correctamente.
2. Confirmar que el navegador o la aplicación móvil estén actualizados.
3. Recargar la página, cerrar y volver a abrir el navegador o la aplicación.
4. Intentar el acceso en una ventana de navegación privada o de incógnito.
5. Desactivar temporalmente extensiones del navegador que puedan interferir.
6. Probar con otro navegador admitido o, en el caso móvil, con otro dispositivo si está disponible.
7. Verificar que la fecha y la hora del equipo sean correctas.
8. Registrar el mensaje de error exacto y, cuando sea posible, tomar una captura de pantalla.
9. Reportar el incidente por los canales definidos en el apartado 1.1.8.

## Limitaciones y consideraciones finales

- Los requerimientos descritos son una línea base y no garantizan por sí solos un rendimiento óptimo; la velocidad percibida también depende de la red, de la carga del servidor y del volumen de información consultado.
- Los entornos no admitidos pueden funcionar de manera parcial, pero no reciben soporte ni compromiso de compatibilidad.
- Las actualizaciones de navegadores, sistemas operativos y aplicaciones móviles pueden modificar los requisitos. La organización revisará este apartado al menos una vez al año o cuando un proveedor anuncie el fin de soporte de una versión relevante.
- Las políticas internas de seguridad, los controles de administración de dispositivos y las restricciones de red prevalecen sobre las recomendaciones generales de este documento.
